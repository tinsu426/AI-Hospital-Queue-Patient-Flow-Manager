#  CareFlow AI – Hospital Queue Management System

CareFlow AI is a hospital management system that helps organize patient queues, improve communication between hospital departments, and make patient flow easier to manage.

##  Features
- Patient registration and queue management
- Patient triage and priority handling
- Doctor and laboratory dashboards
- Real-time queue updates
- AI-based waiting-time prediction
- Interactive hospital navigation
- AI chatbot and voice announcements
- Hospital analytics and administration

##  Technologies
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT, bcryptjs
- **Real-time:** Socket.IO
- **Voice:** Web Speech API

##  Getting Started

**1. Clone the repository**
```bash
git clone YOUR_REPOSITORY_URL
cd ai-hospital-queue-manager
```

**2. Install dependencies**

Install dependencies in the root, client, and server directories as needed.

**3. Configure your environment**

Create a `.env` file inside the server directory using `.env.example`.

**4. Start the backend**
```bash
cd server
npm start
```

**5. Start the frontend**
```bash
cd client
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
